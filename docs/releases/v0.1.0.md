## Deploy notes
- Set `AUTH_SECRET` (32+ characters), `ADMIN_USERNAME` and `ADMIN_PASSWORD` (12+ characters) before the first start. Without `AUTH_SECRET` login returns 503.
- `ADMIN_TOKEN` and the `X-Admin-Token` header are removed.
- `COOKIE_SECURE` defaults to true; set `false` only for plain-http local use.
- A new `users` table is created on startup; existing appointments are unchanged.
- The seed admin must change the password at first sign-in. Restart the server after running `seed_admin.py`.
