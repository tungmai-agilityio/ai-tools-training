2. Open the appointment list with 5 per page
3. Scroll to the bottom of page 1 and note the last person.
4. Load page 2 (scroll or "next") and look at the first row.

- Page 2 returns 6 items, and its first item is the last item of page 1.

## Expected Behavior

- Each page returns exactly page_size items, except the last, which returns only the remaining rows.
