# Match the Revenue screen to the design and format money with thousands separators

**Sprint:** S-002  **Feature:** revenue-chart  **Type:** Feature  **Priority:** Low  **Estimate:** XS  **Push:** Ready  **Plan:** Approved
**Areas:** ui  **Decisions:** ADR-0001, DDR-0003

## 1. Description
Working Artifact: [UI design](https://claude.ai/artifact/VaAYYy7WoVCPzw2wEwS6jp), board 4. Depends on T-032 (same render function; do it after to avoid conflicts).

Bring the Revenue screen in line with the design and show amounts as `$2,610.00` everywhere. Today the shared `money()` helper prints `$2250.00`. Plan: [plan.md](../features/revenue-chart/plan.md).

## 2. Business rules
None. Display only; money stays integer cents.

## 3. Constraints
- Change the shared `money()` helper in `app/static/app.js` (all screens use it); update every existing test string that asserts the old format. No existing test is weakened or deleted.
- Frontend only; no API change, no dependency.

## 4. Acceptance criteria
- AC-1 Given any screen that shows money, then amounts show a thousands separator and two decimals (`$2,610.00`, `$0.00`, `$12.50`).
- AC-2 Given the Revenue results, then the summary cards read Total revenue, Consultations ("Completed visits"), Penalties ("No-shows and late cancels"), in that order.
- AC-3 Given the Revenue screen, then From, To and the "Show report" button sit in the page header (wrapping on a phone), and the note under the title reads "Gross, in clinic time (<zone>). Each visit counts on the day it was scheduled."
- AC-4 Given a wide screen, then the by-doctor table sits beside the chart card; on a phone they stack.
- AC-5 `pytest` passes; no CSP violation; no sideways page scroll at 375px.

## 6. Out of scope
