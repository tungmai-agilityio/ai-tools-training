# Run pytest and browser tests in CI on every PR

**Type:** Chore  **Priority:** High  **Estimate:** S  **Push:** Draft
**Areas:** ci  **Decisions:** ADR-0004

> Claude-assisted draft for Tung to edit.

## Why
No workflow runs `pytest` today (`.github/workflows/` has only `claude.yml` and `security.yml`), so "suite green" is a local claim. ADR-0004 adds one CI job for the whole suite, browser tests included.

## What
- New workflow `.github/workflows/tests.yml` on `pull_request` to `develop` (and `push` to `develop`): Python from `requirements-dev.txt`, `playwright install --with-deps chromium`, browser cache keyed on the Playwright version.
- Set `REQUIRE_BROWSER=1` in CI so a missing browser fails instead of skipping; locally the browser tests still skip.
- Upload `test-artifacts/screenshots/` with `actions/upload-artifact`, `retention-days: 14`, also when tests fail.
- Least-privilege `permissions: contents: read`. Fake data only; no secrets needed.
- After one week with no flaky run, Tung makes the job a required check on `develop` (repo setting, not code).

## Done when
- [ ] A PR to `develop` shows the tests job; it fails on a failing test and on a missing browser.
- [ ] Screenshots are downloadable from the run for 14 days.
- [ ] The job finishes in under 5 minutes on a warm cache.
