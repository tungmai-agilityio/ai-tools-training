# Run pytest and browser tests in CI on every PR

**Type:** Chore  **Priority:** High  **Estimate:** S  **Push:** Ready
**Areas:** ci  **Decisions:** ADR-0004

> Claude-assisted draft for maintainer edit.

## Why
No workflow runs `pytest` today (`.github/workflows/` has only `claude.yml` and `security.yml`), so "suite green" is a local claim. ADR-0004 adds one CI job for the whole suite, browser tests included.

## What
- New workflow `.github/workflows/tests.yml` on `pull_request` to `develop` (and `push` to `develop`): Python from `requirements-dev.txt`, `playwright install --with-deps chromium`, browser cache keyed on the Playwright version.
- Set `REQUIRE_BROWSER=1` in CI so a missing browser fails instead of skipping; locally the browser tests still skip.
- Upload `test-artifacts/screenshots/` with `actions/upload-artifact`, `retention-days: 14`, also when tests fail.
- Trigger with `pull_request`, never `pull_request_target`; `permissions: contents: read`; no repository secrets. Pin third-party actions (`checkout`, `setup-python`, `upload-artifact`) to commit SHAs.
- Pin Playwright to an exact version in `requirements-dev.txt` (it is `>=1.45` today), so every run gets the same browser and the cache key is stable. Pinning adds no new dependency.
- Test-user passwords are throwaway values set in the workflow `env` or generated per run; never a repo secret, never copied from `.env`.
- After one week with no flaky run, a maintainer makes the job a required check on `develop` (repo setting, not code).

## Done when
- [ ] A PR to `develop` shows the tests job; it fails on a failing test and on a missing browser.
- [ ] Screenshots are downloadable from the run for 14 days.
- [ ] The job finishes in under 5 minutes on a warm cache.

## Acceptance criteria and test cases
Add one CI job that runs the whole suite, browser tests included. Depends on nothing; T-025 adds the screenshots the upload step collects.

**Acceptance criteria**
- AC-1 A PR to `develop` shows a `tests` job that runs `pytest` with `REQUIRE_BROWSER=1`.
- AC-2 The job fails on a failing test and on a missing browser (no skip).
- AC-3 `test-artifacts/screenshots/` is uploaded with `retention-days: 14`, also when tests fail.
- AC-4 `permissions: contents: read`, `pull_request` trigger only, no repository secrets, third-party actions pinned to commit SHAs, Playwright pinned to an exact version.
- AC-5 The job finishes in under 5 minutes on a warm cache.

**Test cases**
| ID | AC | Given | When | Then |
|---|---|---|---|---|
| TC-1 | AC-1 | PR with green tests | CI runs | `tests` job passes |
| TC-2 | AC-2 | a deliberately failing test on a throwaway branch | CI runs | job fails |
| TC-3 | AC-2 | browser install step removed on a throwaway branch | CI runs | job fails, not skipped |
| TC-4 | AC-3 | any run | open the run page | artifact downloadable, 14-day retention |
| TC-5 | AC-5 | second run on the same PR | CI runs | duration under 5 minutes |
