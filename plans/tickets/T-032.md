# Show daily revenue as a stacked bar chart

**Sprint:** S-002  **Feature:** revenue-chart  **Type:** Feature  **Priority:** Medium  **Estimate:** S  **Push:** Ready  **Plan:** Approved
**Areas:** ui  **Decisions:** ADR-0001, ADR-0004, DDR-0003

## 1. Description
Working Artifact (BA/QA edit there): [UI design](https://claude.ai/artifact/VaAYYy7WoVCPzw2wEwS6jp), boards 4 and 4b.

The Revenue screen shows revenue by day as a table only. DDR-0003 and the design call for a stacked bar chart (consultation and penalty per day, with a total label on each bar). Add it as hand-written inline SVG built in `app/static/app.js`: no library, no backend change. The by-day table stays behind a "Show as table" toggle. Plan: [plan.md](../features/revenue-chart/plan.md).

## 2. Business rules
None new. The chart shows the `by_day` values the API already returns (`docs/business-rules.md`, "Revenue report"). Money is integer cents.

## 3. Constraints
- No new dependency, no build step; works under `script-src 'self'` (no inline script, no inline event handlers).
- A pure function `revenueChart(by_day)` returns the SVG string; every value is passed through `esc()` and `money()`.
- Colours are theme tokens: consultation `--brand`; penalty a new `--chart-penalty` (light `#b45309`, dark `#f0a35e`). Segments have a 2px surface gap.
- No API, model or stored-data change.

## 4. Acceptance criteria
- AC-1 Given an admin runs the report and `by_day` has rows, then a chart shows one stacked bar per day (consultation below, penalty above), a legend, a $ axis and a total label on each bar.
- AC-2 Given a day with no penalty, then its bar has no penalty segment.
- AC-3 Given `by_day` is empty, then no chart shows and the "No revenue in this range" empty state stays.
- AC-4 Given the chart, then it has `role="img"` and an `aria-label` that names the range and, for up to 14 days, each day's total (longer ranges say the totals are in the table), and the by-day table is available behind "Show as table".
- AC-5 Given more than 14 days with money, then per-bar total labels are dropped and the chart scrolls sideways inside its card; the page does not scroll sideways at 375px.
- AC-6 Given the dark theme, then the chart uses the dark colours and stays readable.
- AC-7 Given doctor names or dates containing markup, then no markup reaches the chart.
- AC-8 `pytest` passes with no existing test weakened; the page loads with no CSP violation.
