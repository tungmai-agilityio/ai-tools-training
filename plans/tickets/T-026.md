## Why

## What
- `docs/references/testing-conventions.md`: browser tests are part of the suite in CI; determinism rules; how to run them and find screenshots.
- `.claude/skills/plan-work`: for a UI ticket, the testing strategy names the screens and states to capture.
- `.claude/skills/implement-ticket`: UI test cases become browser tests, written first; Verify produces the screenshots.
- `.claude/skills/pr` and `.github/pull_request_template.md`: Evidence embeds changed screens at both sizes and links the CI artifact; upload the same PNGs to the feature's UI-design Artifact ("As built").
- `.claude/skills/review-pr`, `REVIEW.md`: missing screenshot evidence for a UI change is a nit; compare screenshots with the UI-design Artifact.
- `README.md`: browser tests section.
