# Capture deterministic desktop and phone screenshots from browser tests

**Type:** Chore  **Priority:** High  **Estimate:** S  **Push:** Ready
**Areas:** tests  **Decisions:** ADR-0004

> Claude-assisted draft for maintainer edit.

## Why
UI changes should ship with the same screenshots every time, as evidence in PRs and in the feature's UI-design Artifact. ADR-0004 makes them a by-product of the browser tests.

## What
- In `tests/test_ui_browser.py` (or a `tests/browser/` conftest if it grows): a `snap(page, name)` helper that saves `test-artifacts/screenshots/<test>-<name>-<desktop|phone>.png` at 1280x800 and 375x812 with `animations="disabled"`.
- Determinism: server clock and browser clock frozen at the suite time, browser timezone `Asia/Ho_Chi_Minh`, fake data via `tests/helpers` and `store.reset()`.
- Fail a test on any CSP violation in the console; never use `bypass_csp`.
- Turn the `importorskip`/launch skip into a failure when `REQUIRE_BROWSER=1`.
- Add `test-artifacts/` to `.gitignore`. Add `snap()` calls to the four existing browser tests. No pixel comparison.

## Done when
- [ ] Running the browser tests twice gives identical screenshots.
- [ ] A page with an inline script fails the CSP check.
- [ ] Plain `pytest` without Playwright still passes (skips); with `REQUIRE_BROWSER=1` it fails.

## Acceptance criteria and test cases
Browser tests save the same desktop and phone screenshots every run. Pairs with T-024 (CI upload). No new dependency.

**Acceptance criteria**
- AC-1 `snap(page, name)` saves `test-artifacts/screenshots/<test>-<name>-{desktop,phone}.png` at 1280x800 and 375x812 with animations disabled and password/token inputs masked.
- AC-2 Two runs produce byte-identical screenshots (clock, timezone and fake data frozen).
- AC-3 A CSP violation in the console fails the test; `bypass_csp` is never used.
- AC-4 `REQUIRE_BROWSER=1` turns the Playwright/Chromium skip into a failure; plain `pytest` still skips.
- AC-5 `test-artifacts/` is gitignored; the four existing browser tests call `snap()`.

**Test cases**
| ID | AC | Given | When | Then |
|---|---|---|---|---|
| TC-1 | AC-1 | existing browser test | runs | both PNGs exist at the stated sizes |
| TC-2 | AC-2 | suite run twice | compare files | identical bytes |
| TC-3 | AC-3 | page with an inline script via `page.route` | CSP check runs | test fails |
| TC-4 | AC-4 | no Chromium, `REQUIRE_BROWSER=1` | pytest | failure |
| TC-5 | AC-4 | no Chromium, variable unset | pytest | skipped |
