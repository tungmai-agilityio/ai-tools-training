# T-009: Let us move an appointment

**Status:** Done  **Type:** Feature  **Priority:** Medium  **Reporter:** Emma (reception)  **Estimate:** S

> Patients keep calling to change their time. Right now we have to cancel and book
> again which is annoying and sometimes charges them. Can you add a way to
> reschedule?

## 1. Summary
Add `POST /appointments/{id}/reschedule` so a scheduled appointment can move to a new time without cancelling. It keeps the same record and doctor, charges no reschedule fee, and the new time passes the normal booking checks. Changing the length updates the consultation fee.

## 2. Analysis
- **Asks:** Add a way to reschedule appointments.
- **Ambiguous:** There is no specification of where to add the UI, no details of what to do with the existing appointment, and no clarification on whether there should be any fee for rescheduling.
- **First step:** Draft questions to clarify the ambiguous requirements with Emma, then discuss with her to make a plan for it.

## 3. Approach
- `app/models.py` → `RescheduleIn(start, duration_minutes)` with the same timezone-aware validation as booking.
- `app/routes.py` → `POST /appointments/{id}/reschedule`: only `scheduled` before start; same record and doctor; ignores the appointment's own slot in the conflict check; validates doctor, patient, lunch, hours and the 60-day limit; updates the fee when the length changes.
- `app/scheduling.py` → reuse the booking validation helpers; no new rules.
- No frontend change in this ticket; the page action is T-010.

## 4. Acceptance criteria
- AC-1 Given a `scheduled` appointment before its start, when it is rescheduled to a free slot, then the same record is updated and no fee is charged.
- AC-2 Given a reschedule inside 24 hours, when it succeeds, then it is still free.
- AC-3 Given a reschedule, when it succeeds, then the old slot is free for other bookings.
- AC-4 Given the appointment's own current slot, when it is chosen as the new time, then it is allowed.
- AC-5 Given a longer visit, when it is rescheduled, then the consultation fee is recalculated.
- AC-6 Given a doctor or patient conflict, when rescheduling, then the API returns 409; lunch or hours return 422.
- AC-7 Given an appointment after its start or in a non-scheduled status, when rescheduling, then the API returns 409.
- AC-8 Given an unknown appointment id, then the API returns 404.
- AC-9 `pytest` passes with no existing test weakened.

## 5. Out of scope
- The web page action (T-010).
- Changing the doctor; the rules say cancel and rebook.
- Reminders, notifications and recurring appointments.

## 6. Business-rule impact
Lifecycle line added to `docs/business-rules.md` (T-009, approved by the clinic manager): a `scheduled` appointment can be rescheduled before its start, keeps the same record and doctor, is free, and the new time passes the same booking checks. Changing the length changes the fee; changing the doctor means cancel and rebook.

## 8. Open questions
None open. The original questions were answered by the approved rule:
1. Reception uses it; patient self-service is out of scope.
2. Free whenever the appointment is still `scheduled` and before its start.
3. Time and length can change; a doctor change means cancel and rebook.
4. The same record is kept, so no cancellation fee is triggered.
5. Reminders, notifications and recurring appointments are out of scope.
