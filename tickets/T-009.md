# T-009: Let us move an appointment

**Status:** In Review  **Type:** Feature  **Priority:** Medium  **Reporter:** Emma (reception)

Patients keep calling to change their time. Right now we have to cancel and book
again which is annoying and sometimes charges them. Can you add a way to
reschedule?

## Analysis

- Asks: Add a way to reschedule appointments
- Ambiguous: There is no specification of where to add the UI, no details of what to do with the existing appointment, and no clarification on whether there should be any fee for rescheduling.
- First step: Draft questions to clarify the ambiguous requirements with Emma, then discuss with her to make a plan for it.

## Clarifying questions

1. Is this for reception to use or should patients be able to reschedule themselves too?
2. When should a reschedule be free, and when should it still carry a fee (for example, too close to the visit)?
3. What do you usually need to change besides the time (doctor, length, ...)?
4. Should a reschedule keep the same appointment record and history, so it never triggers the cancellation fee?
5. What happens to reminders and notifications, and are recurring or prepaid appointments in scope for v1?
