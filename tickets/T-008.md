# T-008: Dr. Mitchell's visit costs $1.50

**Status:** Done  **Type:** Bug  **Severity:** S2 wrong money  **Priority:** High  **Reporter:** Emma (reception)

> A patient booked with Dr. Mitchell and the fee shows $1.50. The other doctors look
> normal. We are sure it is not that cheap. Please fix the calculation.

## 1. Summary
Dr. Mitchell's base fee in `data/seed.json` was stored as 150 cents instead of 15000 cents, so a 30-minute visit cost $1.50. The fee calculation itself was correct.

## 2. Environment
- Build / commit: fix `cfee166`, merged in `c06d1d7`.
- Where: API and UI — appointment fee.
- Config: default.
- Clock: not time-dependent.

## 3. Steps to reproduce
1. Book a 30-minute visit with Dr. Mitchell.
2. Read the fee in the response or the confirmation toast.

## 4. Actual behaviour
- The consultation fee was 150 cents ($1.50).

## 5. Expected behaviour
Rule: "Each doctor has a base fee for 30 minutes." (`docs/business-rules.md`)
- AC-1 Given a 30-minute visit with Dr. Mitchell, when the fee is calculated, then it is 15000 cents.

## 6. Analysis
- **Asks:** Charge Dr. Mitchell's correct base fee.
- **Ambiguous:** The report named only the symptom; the doctor's correct fee was not in the ticket.
- **Root cause:** `data/seed.json` had `"fee_cents": 150` for Dr. Mitchell; every other doctor was correct (`cfee166`).
- **Bug type:** data

## 7. Clarifying questions
None recorded. Only Dr. Mitchell's record differed from the other doctors.

## 8. Fix and test
- Regression test: `tests/test_booking.py::test_dr_mitchell_30_minute_visit_costs_150_dollars`.
- Fix: set `fee_cents` to 15000 in `data/seed.json`.
