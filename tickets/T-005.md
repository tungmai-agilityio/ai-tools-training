# T-005: Patient cancelled a visit that already happened

**Status:** Done  **Type:** Bug  **Severity:** S2 wrong money  **Priority:** Medium  **Reporter:** Emma (reception)

> A patient called and asked us to "cancel" her visit from last week so she is not
> charged. We pressed cancel and the system just did it! Is that OK? I don't think
> so but also sometimes patients really do leave halfway, so what should the system
> do in those cases? Please make it right.

## 1. Summary
Cancel was accepted after an appointment had started, and for completed or no-show visits. There was also no way to mark a checked-in patient who left before being seen.

## 2. Environment
- Build / commit: fix `5695c10`, merged in `2d9e804`.
- Where: API and UI — Cancel action (`POST /appointments/{id}/cancel`).
- Config: default.
- Clock: at or after the appointment start.

## 3. Steps to reproduce
1. Book an appointment and move the frozen clock past its start time.
2. Press Cancel, or call `POST /appointments/{id}/cancel`.
3. Repeat on a completed or no-show appointment.

## 4. Actual behaviour
- The cancel was accepted, so a past visit could avoid its fee.
- A checked-in patient who left could only be marked completed or left as checked in.

## 5. Expected behaviour
Rules: "Only a `scheduled` appointment can be cancelled, and only before its start time." and "A patient who checks in but leaves before being seen is marked `left_unseen`. No fee." (`docs/business-rules.md`, T-005, pending clinic manager confirmation)
- AC-1 Given a `scheduled` appointment before its start, when it is cancelled, then it succeeds.
- AC-2 Given a completed, no-show, or already-started appointment, when it is cancelled, then the API returns 409.
- AC-3 Given a checked-in appointment, when it is marked left unseen, then the status is `left_unseen` and the fee is 0.
- AC-4 Given a `scheduled` or completed appointment, when left unseen is requested, then the API returns 409.

## 6. Analysis
- **Asks:** Stop cancelling visits that already happened, and give staff a correct way to close a patient who left.
- **Ambiguous:** Whether a late cancellation should charge, and what "left halfway" should cost.
- **Root cause:** The cancel endpoint had no status or start-time guard, and `TRANSITIONS` only allowed `checked_in -> completed`; `left_unseen` did not exist (`5695c10`).
- **Bug type:** code

## 7. Clarifying questions
1. Should a patient who leaves before being seen pay anything?
2. Should the clinic be able to waive a late-cancellation fee?
3. What should happen to an appointment that is still `scheduled` after its start time?

Answered in `docs/business-rules.md` (T-005, pending clinic manager confirmation); kept for the record.
